## 画布可用空间

| 1366 × 768 | 748 × 191 | 800 × 449 | 设计面板、画布和检查器同时显示，画布面积为原来的 2.51 倍 |
| 1840 × 1000 | 1222 × 381 | 1274 × 681 | 三栏同时显示，画布面积为原来的 1.86 倍 |

## 功能与数据核对

| 验收对象 | 检查内容和结果 |
| --- | --- |
| 画布和导航 | Ctrl+F 定位真实实例，多上游候选跳转后按历史返回。F11 与 Esc 往返后，模型布局、选中实例、缩放与视口中心均一致。 |
| 小窗口 | 选中器件后显示检查器，可返回设计面板。提取选项可展开并收起，操作前后的配置一致。器件图例包含根、末端和聚合标记。 |
| 模块与端口 | 在 DIV 规则中检测缺失的 module 名，补齐后通过缓存端口预览筛选输入。实时勾选计数为 1，保存后保留时钟端口及 div、sw_done 的实际接口名。 |
| 分支与分析 | 独立分支窗口显示 9 个器件。检查器、问题表、寄存器追踪和 SV 模板入口均可操作。复位树模式下的时钟分支 SV 入口禁用。 |
| 结果导出 | 从文件菜单导出全量 JSON 后，逐项比对节点和边。导出的当前视图 SVG 可被 XML 解析器读取。 |
| 真实 EDA | 在 VM 上从 GUI 启动 Verdi O-2018.09-SP2 读取既有 KDB。运行中阶段面板自动展开，完成后比对全部 8 个真实实例及 7 条连接的两端实例和端口，均与已知结果一致。 |
| SV 工作流 | 在原生 Tk 中导入模板和宏并生成 SV，结束进程后再次启动，恢复模板配置、分支计划及实际 SV 文件。 |
| 大图 | 单独使用 100,000 实例的合成索引图。分支高亮覆盖 99,999 条真实边，取消布局后恢复视图，过期布局结果被丢弃。6 次采样均为 35 个概览图元、GUI RSS 55,864 KiB，未记录 Tk 回调异常。该 RSS 仅对应本次概览压力样例。 |
| 自动回归 | Linux VM 上 461 项通过。Windows 上 460 项通过，1 项 Linux Verdi 包装脚本和符号链接测试按平台跳过。 |

## 复现

在仓库或解压后的便携包目录中运行，结果保存在所选输出目录。功能检查需要图形会话。Linux 可通过 Xvfb 运行，添加 `--capture` 可保存 X11 窗口截图。

```bash
python3 scripts/check_gui_workspace.py --geometry 1366x768 --exercise --out /tmp/ct7-gui-check
python3 scripts/check_workbench_gui.py --phase stress --result examples/device_models/clocktree.json --out /tmp/ct7-gui-stress
```

`check_gui_workspace.py` 的 `--root` 可指向对照版源码，在不带 `--exercise` 时测量旧版。真实 EDA 检查可追加 `--extract-config /path/to/config.json`，该配置旁需有用于逐端口对比的 `clocktree.json`。操作入口及对应界面见[新版 GUI 操作手册](GUI_USER_MANUAL.zh-CN.md#workspace)。
