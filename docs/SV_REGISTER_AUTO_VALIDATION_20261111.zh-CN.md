# SV 自动选择最新寄存器结果验收

日期：2026-11-11。共享工作区：`D:/VMshare/clocktree7`。

## 行为

SV 窗口默认自动选择当前设计及分析类型最新完成的寄存器结果，排序依据为 `register-trace.json` 生成/更新时间。只检查运行目录 `.register-trace` 下的任务，以及已保存/导入的结果位置和同级任务，不递归扫描 RTL。要求匹配设计入口、已完成摘要以及 manifest/SQLite 必要文件；运行中、中断、其他设计或缺失/明显损坏结果不自动选入。含未解析或候选歧义的已完成任务正常选入，由原有分支规则处理。

在打开窗口、开始分析、导出及从寄存器追踪窗口返回时刷新。手动选择/编辑目录会关闭本窗口的自动选择，勾选“自动选择最新”即可恢复。新打开的窗口默认重新自动选择。

分支计划保存寄存器目录及三个结果文件的版本标记（路径、大小、纳秒修改时间）。改变目录或原目录结果更新后，旧计划停止导出，要求重新分析；模板和候选选择保留。版本标记用于发现结果更新，不宣称代替数据库内容的密码学完整性校验。寄存器算法和 NPI 追踪没有修改。
